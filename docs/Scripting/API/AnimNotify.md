# fjell::AnimNotify / fjell::AnimNotifyState

Base classes for animation notifies — callbacks fired from the animation timeline.

| | |
|---|---|
| Header | `fjell/notify.hpp` |
| Source | (header-only base; engine dispatch in `src/animation/anim_notify_registry.cpp`) |

## Syntax

```cpp
namespace fjell {

struct AnimNotify {
    virtual ~AnimNotify() = default;
    virtual void notify(Node3D& owner) = 0;
    [[nodiscard]] virtual const char* notify_type_name() const = 0;
    [[nodiscard]] virtual bool is_state() const;   // returns false
};

struct AnimNotifyState : public AnimNotify {
    void notify(Node3D&) override;          // no-op; satisfies base
    [[nodiscard]] bool is_state() const override;   // returns true

    virtual void notify_begin(Node3D& owner) = 0;
    virtual void notify_tick (Node3D& owner, float dt) = 0;
    virtual void notify_end  (Node3D& owner) = 0;
};

}
```

## Remarks

Notifies are timeline events authored alongside animation clips. The state machine fires them as the playhead crosses their authored time:

- **`AnimNotify`** — instant. Single `notify()` call when the timeline crosses the notify's time.
- **`AnimNotifyState`** — spans a time range. `notify_begin` when entered, `notify_tick(dt)` each frame the range is active, `notify_end` when exited (or interrupted by a transition).

The `Node3D& owner` parameter is the node carrying the `AnimatorComponent` that's playing the clip — typically the character. Use it to look up sibling components, spawn effects at the character's position, etc.

Register via `FJELL_NOTIFY(MyNotify)`. Reflected fields (`[[fj::property]]`) appear in the notify's editor inspector so designers can tune per-instance values (volume, color, etc.).

## AnimNotify

Base for instant notifies.

### Member functions

| Name | Description |
|---|---|
| Destructor | Virtual. |
| [`notify`](#animnotifynotify) | Called when the timeline crosses this notify's time. Override required. |
| [`notify_type_name`](#animnotifynotify_type_name) | Returns the registered type name. Provided by `FJELL_NOTIFY`. |
| [`is_state`](#animnotifyis_state) | `false` for `AnimNotify`, `true` for `AnimNotifyState`. |

---

### AnimNotify::notify

```cpp
virtual void notify(Node3D& owner) = 0;
```

Called once when the playhead crosses the notify's authored time. Self-contained — do whatever the event represents (play sound, spawn VFX, set a flag on a component, etc.) and return.

#### Parameters
| Name | Type | Description |
|---|---|---|
| `owner` | `Node3D&` | The node carrying the animator that fired this. |

#### Example
```cpp
struct FootstepNotify : public fjell::AnimNotify {
    FJELL_NOTIFY(FootstepNotify)

    [[fj::property]] float volume{1.0f};

    void notify(fjell::Node3D& owner) override {
        // Could play a sound here using owner.position()
        fjell::Log::info_f("step! volume=%.2f", volume);
    }
};
```

---

### AnimNotify::notify_type_name

```cpp
[[nodiscard]] virtual const char* notify_type_name() const = 0;
```

Returns the type's registered string name. Implementation is generated by `FJELL_NOTIFY(T)` — you don't write it manually.

---

### AnimNotify::is_state

```cpp
[[nodiscard]] virtual bool is_state() const;   // base: returns false
```

`false` for instant notifies, `true` for state notifies. Used by the engine to dispatch the right callback set.

## AnimNotifyState

Base for time-ranged notifies. Inherits from `AnimNotify` and replaces the single `notify()` with begin/tick/end.

### Member functions

| Name | Description |
|---|---|
| [`notify_begin`](#animnotifystatenotify_begin) | Called when the playhead enters the range |
| [`notify_tick`](#animnotifystatenotify_tick) | Called each frame the range is active |
| [`notify_end`](#animnotifystatenotify_end) | Called when the playhead leaves the range (or transition interrupts) |

The inherited `notify(Node3D&)` is overridden as a no-op — you don't need to override it. `is_state()` returns `true`.

---

### AnimNotifyState::notify_begin

```cpp
virtual void notify_begin(Node3D& owner) = 0;
```

Called once when the playhead crosses the start of the range. Acquire resources here (spawn a persistent VFX emitter, enable a hitbox, etc.).

---

### AnimNotifyState::notify_tick

```cpp
virtual void notify_tick(Node3D& owner, float dt) = 0;
```

Called every frame the range is active. `dt` is scaled gameplay time. Update whatever ongoing effect this state represents.

#### Parameters
| Name | Type | Description |
|---|---|---|
| `owner` | `Node3D&` | The animator's node. |
| `dt` | `float` | Scaled gameplay seconds since the last tick. |

---

### AnimNotifyState::notify_end

```cpp
virtual void notify_end(Node3D& owner) = 0;
```

Called once when the playhead leaves the range — either by reaching the end normally or by a state transition cutting the clip short. Mirror whatever `notify_begin` set up.

The engine guarantees `notify_end` will fire for every `notify_begin` that fired, even if the animation was interrupted.

## Patterns

### Instant footstep sound

```cpp
struct FootstepNotify : public fjell::AnimNotify {
    FJELL_NOTIFY(FootstepNotify)

    [[fj::property]] fjell::Asset<fjell::Audio> sound;
    [[fj::property]] float volume{1.0f};

    void notify(fjell::Node3D& owner) override {
        fjell::audio::play(sound, owner.position(), volume);
    }
};
```

### Hitbox active during a swing

```cpp
struct AttackWindow : public fjell::AnimNotifyState {
    FJELL_NOTIFY(AttackWindow)

    [[fj::property]] float damage{10.0f};

    void notify_begin(fjell::Node3D& owner) override {
        if (auto hb = owner.get_component<Hitbox>()) hb->enable(damage);
    }
    void notify_tick(fjell::Node3D&, float /*dt*/) override {}
    void notify_end(fjell::Node3D& owner) override {
        if (auto hb = owner.get_component<Hitbox>()) hb->disable();
    }
};
```
